# IPTV na TV — Streaming Smart TV 4K para Samsung, LG e Android

Plataforma oficial do **IPTV na TV** (`iptvnatv.online`), especializada em streaming de alta estabilidade diretamente em televisores Samsung, LG, TCL, Android TV, Fire TV Stick e TV Box com mais de 35.000 canais e filmes.

## 🚀 Tecnologias

- **Framework**: TanStack Start + Vite + React 19
- **Estilização**: Tailwind CSS v4 + Radix UI + Lucide React
- **SEO & Otimização**: Schema.org estruturado (Product, FAQPage, HowTo, BlogPosting, OfferCatalog), OpenGraph completo, Canonical Tags dinâmicas, Sitemap XML e RSS Feed nativo.
- **Identidade Visual**: Backdrop cinematográfico *The Batman* otimizado em WebP leve (~54 KB), paleta Gotham Obsidian & Ruby Red com botões High-Voltage Gold de alto contraste e legibilidade para TV e mobile.

## 💻 Executando localmente

```sh
git clone https://github.com/kegino/iptv-na-tv.git
cd iptv-na-tv
pnpm install
pnpm dev
```

## 📦 Build para Produção

```sh
pnpm build
```
